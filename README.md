# pretty-print-json
PrettyJson — небольшая Java-библиотека для форматирования JSON. Она делает JSON читаемым для человека, добавляя отступы, переносы строк и пробелы после двоеточий. Поддерживает как валидный, так и невалидный JSON, а размер отступа можно настроить.
Библиотека предназначена для использования в консольных приложениях или других проектах, где важно красиво выводить JSON.
